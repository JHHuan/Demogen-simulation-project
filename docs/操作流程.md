# 操作流程

本文档详细介绍从数据采集到策略评估的完整操作流程。

## 前置条件

确保已按照 [环境配置](环境配置.md) 完成所有依赖安装。

## 流程总览

```
Step 1: 遥操作数据采集
    ↓
Step 2: Pickle → Zarr 格式转换
    ↓
Step 3: SAM 图像分割
    ↓
Step 4: 合成演示数据生成
    ↓
Step 5: DP3 策略训练
    ↓
Step 6: 仿真评估
```

---

## Step 1: 遥操作数据采集

使用 RoboPal 键盘遥操作 Panda 机械臂完成目标任务，采集演示数据。采集脚本位于 `robopal/robopal/collect_data/`。

### 1.1 启动遥操作

以单立方体抓取为例：

```bash
python robopal/robopal/collect_data/pick_cube.py
```

> `collect_data/` 目录下还提供了其他任务的采集脚本：`pick_cube_1.py`（场景变体）、`pick_cube_2cam.py`（双相机对比）、`task1_teleop.py`（双物体）、`press_button_2cam.py`（按钮按压）、`assembly_2cam.py`（装配）、`pick_cube_o6hand.py`（灵巧手），根据任务需要选择对应脚本。

### 1.2 键盘操作

| 按键 | 功能 |
|------|------|
| ↑ / ↓ / ← / → | 末端执行器在 x/y 平面移动 |
| Ctrl + ↑ / ↓ | z 轴上/下移动 |
| CapsLock | 切换夹爪开/闭状态 |
| 空格键 | 手动录制当前状态一帧 |
| r | 重置环境 |
| a | 保存轨迹为 pickle 文件 |
| c | 清除当前轨迹 |
| ESC | 退出程序 |

### 1.3 操作步骤

1. 弹出仿真窗口后，使用键盘控制 Panda 机械臂完成抓取任务
2. 每次按键控制时，程序会自动采集一帧数据（点云、RGB、深度、位姿、动作）
3. 夹爪状态变化时会自动等待并额外录制一帧，确保夹爪动作完整
4. 完成演示后按 **a** 保存轨迹
5. 程序退出时若有未保存数据会自动紧急保存（`_autosave.pkl`）
6. 数据保存路径：`robopal/robopal/collect_data/collected_data/<时间戳>/`

### 1.4 自动生成 SAM 图像

程序启动后会自动：
- 等待环境稳定（100 步仿真）
- 使用高分辨率渲染器（1920×1080）渲染第一帧
- 保存到 `sam_mask_dir`（默认为 `DemoGen-master/data/sam_mask/source.jpg`）

如需修改保存路径，编辑采集脚本中的 `sam_mask_dir` 变量。

### 1.5 复制数据

将采集的 pickle 文件复制到 DemoGen 数据目录：

```bash
cp robopal/robopal/collect_data/collected_data/<时间戳>/*.pkl \
   DemoGen-master/data/source_demos/<任务名>/
```

`<任务名>` 应与后续配置文件中 `source_name` 一致，例如 `0219-cube`。

---

## Step 2: Pickle → Zarr 格式转换

将 pickle 格式的演示数据打包为 Zarr 格式，供 DemoGen 和 DP3 训练使用。


```bash
cd DemoGen-master
python merge_zarr.py <实验名称>
```

- 读取路径：`data/source_demos/<实验名称>/`
- 输出路径：`data/datasets/source/<实验名称>.zarr`
---

## Step 3: SAM 图像分割

使用 Segment Anything Model 对第一帧图像中的目标物体进行分割，生成掩码。

### 3.1 准备图像

Step 1 中程序已在 `sam_mask_dir` 路径下自动保存了第一帧图像 `source.jpg`。

### 3.2 执行分割

```bash
cd DemoGen-master/data/sam_mask
python segment_interactive.py \
    --image "<实验名>/source.jpg" \
    --output "<实验名>/<物体名>.jpg"
```

### 3.3 交互操作

| 操作 | 功能 |
|------|------|
| 鼠标左键 | 选择前景点（绿色标记） |
| 鼠标右键 | 选择背景点（红色标记） |
| s | 执行分割 |
| q | 保存掩码并退出 |

### 3.4 输出

分割掩码保存为 `<物体名>.jpg`，后续 DemoGen 会根据配置中的 `mask_names` 字段加载对应掩码。例如 `cube.yaml` 中 `mask_names.object: green cube` 对应掩码文件 `green cube.jpg`。

---

## Step 4: 合成演示数据生成

通过空间增强将单条演示扩展为数百条合成演示数据。

### 4.1 配置说明

任务配置文件位于 `DemoGen-master/demo_generation/demo_generation/config/`，以 `cube.yaml` 为例：

```yaml
_target_: demo_generation.demogen.DemoGen
data_root: data
source_name: 0219-cube           # 与 Step 2 中的实验名一致

task_n_object: 1

mask_names:
  object: green cube              # 与 Step 3 中的掩码文件名一致

trans_range:
  src:                            # 源数据范围（无偏移）
    object: [[0, 0, 0], [0, 0, 0]]
  test:                           # 测试范围（XY 平移 ±0.15m）
    object: [[-0.15, -0.15, 0], [0.15, 0.15, 0]]

generation:
  range_name: test                # 使用哪个平移范围
  n_gen_per_source: 16            # 每条源演示生成数量
  render_video: True              # 是否渲染视频
  mode: grid                      # 采样模式: grid / random
```

### 4.2 单任务生成

```bash
cd DemoGen-master/demo_generation
bash gen_demo.sh <任务名> <范围> <模式> <数量> <渲染>
```

**参数说明**：

| 参数 | 说明 | 示例 |
|------|------|------|
| 任务名 | `config/` 下的 YAML 文件名（不含后缀） | `cube`, `mug`, `egg` |
| 范围 | 平移范围名（对应配置中的 `trans_range` 键） | `test`, `src` |
| 模式 | 采样方式 | `grid`（均匀网格）/ `random`（随机） |
| 数量 | 每条源演示的生成数 | `16`, `9`, `81` |
| 渲染 | 是否生成渲染视频 | `true` / `false` |

**示例**：

```bash
# 生成 16 条网格采样数据
bash gen_demo.sh cube test grid 16 true

# 生成 81 条数据（9×9 网格）
bash gen_demo.sh cube test grid 81 true

# 随机采样 1 条
bash gen_demo.sh cube src random 1 true
```

### 4.3 批量生成

```bash
bash run_gen_demo.sh
```

该脚本会依次为多个任务生成数据（task1, mug, egg, sauce, flower）。

### 4.4 输出

生成数据保存到 `data/datasets/generated/<任务名>.zarr`。

## Step 5: DP3 策略训练

使用 3D Diffusion Policy 在合成数据上训练视觉运动策略。

### 5.1 训练命令

```bash
cd DemoGen-master/diffusion_policies
bash train.sh <实验名> <算法> <任务> <种子>
```

**参数说明**：

| 参数 | 说明 | 示例 |
|------|------|------|
| 实验名 | 对应生成数据的 Zarr 文件名（不含 `.zarr`） | `0219-cube_test_225` |
| 算法 | 策略配置名（对应 `config/` 下的 YAML） | `dp3`, `simple_dp3`, `idp3` |
| 任务 | 任务定义名（对应 `config/task/` 下的 YAML） | `cube`, `oyhand` |
| 种子 | 随机种子 | `0`, `1`, `2` |

**示例**：

```bash
bash train.sh 0219-cube_test_225-dp3 dp3 cube 0
```

### 5.2 关键训练超参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `horizon` | 16 | 动作预测时间窗口 |
| `n_obs_steps` | 2 | 观测历史步数 |
| `n_action_steps` | 8 | 单次预测动作步数 |
| `batch_size` | 24 | 训练批大小 |
| `lr` | 1e-4 | 学习率 |
| `num_epochs` | 1000 | 训练轮数 |
| `use_ema` | True | 是否使用指数移动平均 |

### 5.4 监控训练

训练日志通过 `logging.mode` 控制：
- `disabled`：不记录日志（默认）
- `offline`：使用 WandB 离线记录
- `online`：使用 WandB 在线记录

模型检查点保存到：`data/ckpts/<实验名>/checkpoints/`

### 5.5 修改训练任务数据路径

训练任务配置在 `diffusion_policies/config/task/cube.yaml` 中定义了数据集路径：

```yaml
dataset:
  zarr_path: /path/to/your/generated/data.zarr
```

`train.sh` 会通过命令行参数覆盖此路径，但如果不使用 `train.sh`，需要手动修改此配置。

## Step 6: 仿真评估

在 MuJoCo 仿真环境中评估训练好的策略。
使用 `replay_eva/eva_pick_cube_0.py` 进行多 episode 评估：

```bash
cd DemoGen-master/replay_eva

python eva_pick_cube_0.py \
    --checkpoint ../../data/ckpts/<实验名>/checkpoints/<编号>.ckpt \
    --n_episodes 10 \
    --headless \
    --save_video \
    --video_dir ./recorded_videos
```

**完整参数**：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `--checkpoint` | （必填） | 模型检查点路径 |
| `--n_episodes` | 10 | 评估 episode 数量 |
| `--use_ema` | False | 使用 EMA 模型推理（推荐开启） |
| `--seed` | 42 | 随机种子 |
| `--headless` | False | 无头模式，不显示仿真窗口（更快） |
| `--save_video` | False | 保存每个 episode 的视频 |
| `--video_dir` | `./recorded_videos` | 视频保存目录 |
| `--video_fps` | 30 | 视频帧率 |
| `--video_width` | 640 | 视频宽度 |
| `--video_height` | 480 | 视频高度 |
