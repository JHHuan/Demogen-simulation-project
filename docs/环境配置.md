# 环境配置

本文档详细介绍 DemoGen-Simulation 项目的完整环境搭建流程。

## 1. 系统要求

| 项目 | 要求 |
|------|------|
| 操作系统 | Linux（推荐 Ubuntu 20.04+） |
| Python | 3.8 |
| Conda | Miniconda 或 Anaconda |
| GPU | NVIDIA GPU（训练需要 CUDA 支持） |
| 内存 | 建议 ≥ 8 GB |

## 2. 创建 Conda 环境

```bash
conda create -n demogen python=3.8
conda activate demogen
```

## 3. 安装基础依赖

```bash
pip3 install imageio imageio-ffmpeg termcolor hydra-core==1.2.0 \
    zarr==2.12.0 matplotlib setuptools==59.5.0 pynput h5py \
    scikit-video tqdm

pip install numpy scipy scikit-learn pillow opencv-python
```

## 4. 安装 PyTorch

根据你的 CUDA 版本安装 PyTorch（以 CUDA 11.8 为例）：

```bash
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu118
```

> 可在 [PyTorch 官网](https://pytorch.org/get-started/locally/) 查看对应版本的安装命令。

## 5. 安装 MuJoCo

```bash
pip install mujoco
```

## 6. 安装 Diffusers

DP3 训练依赖 HuggingFace Diffusers 库：

```bash
pip install diffusers
```

## 7. 安装项目子模块

按以下顺序安装各子模块：

### 7.1 安装 Diffusion Policies

```bash
cd DemoGen-master/diffusion_policies
pip install -e .
cd ../..
```

### 7.2 安装 DemoGen

```bash
cd DemoGen-master/demo_generation
pip install -e .
cd ../..
```

### 7.3 安装 RoboPal

RoboPal 已针对 DemoGen 做了适配修改：
- 修复 Python 3.8 兼容性问题
- 添加 DemoGen 相机配置 (`demogen_camera`)
- 实现标准数据格式输出（点云、RGB、深度、位姿、动作）

```bash
cd robopal
pip install -r requirements.txt
pip install -e .
cd ..
```

## 8. 安装 SAM（可选）

如果需要使用 Segment Anything Model 进行目标物体分割：

```bash
pip install segment-anything
```

并将 SAM 预训练权重放置到：

```
DemoGen-master/data/sam_mask/weights/
```

> 权重文件可从 [SAM 官方仓库](https://github.com/facebookresearch/segment-anything#model-checkpoints) 下载。

## 9. 安装验证

### 9.1 验证 RoboPal 环境

运行数据采集脚本，验证 MuJoCo 仿真环境正常启动：

```bash
python robopal/robopal/collect_data/pick_cube.py
```

如果弹出仿真窗口并能通过键盘控制 Panda 机械臂，说明环境配置成功。
